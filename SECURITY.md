# Security

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/bearylaw/minecraft-kinora-replay-mod/security/advisories/new),
not in a public issue.

Examples: a crafted `.kinora` replay or `.kinoraproj` project that runs code, writes files outside
the Kinora folders, or crashes the game in a way that could be abused.

Only the newest release is supported with fixes.
